Poisson process WRITE BIG · you got 0/3

Rate λ per unit time. First ask: is it HOW MANY or HOW LONG? Convert the time units first (20 min = 1/3 h).

HOW MANY in time t: X ~ Poisson(μ = λt) P(X = k) = e^(−μ) μ^k / k! E = Var = μ, SD = √μ P(0) = e^(−μ) P(≥1) = 1 − e^(−μ) P(≤1) = e^(−μ)(1 + μ) P(≥2) = 1 − e^(−μ)(1 + μ) HOW LONG until next: T ~ Exp(λ) P(T > t) = e^(−λt) F(t) = 1 − e^(−λt) E = 1/λ median = ln2 / λ Poisson approx to Bin(n,p): n big, p small → μ = np

Example: 8 aircraft/h. P(≥2 in 1 h) = 1 − e⁻⁸(1+8) = 0.997. Wait > 20 min: e^(−8·⅓) = 0.0695.

Finding μ is not the answer. Put μ into the formula.

Transformation U = g(Y) WRITE BIG · you got 0/2

1. F_Y(y) = ∫ f 2. G(u) = P(U ≤ u) → rearrange to P(Y ≤ ___) 3. G(u) = F_Y(___) 4. g(u) = G′(u) ← CHAIN RULE: × (derivative of ___) 5. Support: put the y endpoints into U CHECK: ∫ g(u) du = 1

Example: f = 2y on [0,1], U = 4Y − 1. G = ((u+1)/4)² → g = 2·(u+1)/4·¼ = (u+1)/8 on [−1, 3].

E(aY + b) = a·E(Y) + b Var(aY + b) = a²·Var(Y)

E(Y) = ∫ y·f(y) dy. Multiply by y first.

Bayes / total probability WRITE BIG

P(D) = P(D|A)P(A) + P(D|B)P(B) + P(D|C)P(C) P(C|D) = P(D|C)P(C) / P(D) ← DIVIDE by P(D)!

Write each product on its own line, then add them. Define the events in words first (that earns a mark).

P(A∪B) = P(A) + P(B) − P(A∩B) P(A|B) = P(A∩B)/P(B) Indep: P(A∩B) = P(A)P(B) Disjoint: P(A∩B) = 0 pmf conditional: P(X≤3 | X≥1) = P(1≤X≤3)/P(X≥1)

Sums, max, min WRITE BIG

Var(aX ± bY) = a²Var X + b²Var Y (indep.) ← always + Total of n: E = nμ, Var = nσ², SD = σ√n Average of n: E = μ, SD = σ/√n ADD VARIANCES, NOT SDs. SERIES = min = use P(>): P(min > t) = P(X₁>t)P(X₂>t)… PARALLEL = max = use P(≤): P(max ≤ t) = F₁(t)F₂(t)…
