1 · Descriptive statistics

x̄ = Σxᵢ / n s² = Σ(xᵢ − x̄)² / (n − 1) IQR = Q3 − Q1 Outlier if < Q1 − 1.5·IQR or > Q3 + 1.5·IQR

Skew: the mean is pulled toward the tail. Right-skewed (tail on the right): mean > median. Left-skewed: mean < median.

For y = a + b·x: centres (mean, median, Q1, Q3) become a + b·(old). Spreads (SD, IQR, range) become |b|·(old). Variance becomes b²·(old). Adding a doesn't change spread.

Reading a histogram: with relative frequency, the proportion in an interval is the sum of the bar heights. Multiply by n to get counts.

3 · Probability

P(Aᶜ) = 1 − P(A) P(A ∪ B) = P(A) + P(B) − P(A ∩ B) P(A | B) = P(A ∩ B) / P(B) P(A ∩ B) = P(A | B)·P(B) Independent ⇔ P(A ∩ B) = P(A)·P(B) ⇔ P(A|B) = P(A) Disjoint ⇔ P(A ∩ B) = 0 De Morgan: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ P(at least one) = 1 − P(none)

Total probability: P(A) = Σ P(A | Bᵢ)P(Bᵢ), where the Bᵢ partition the sample space.

Bayes: P(Bⱼ | A) = P(A | Bⱼ)P(Bⱼ) / Σ P(A | Bᵢ)P(Bᵢ)

Two disjoint events with positive probabilities are never independent. If S = A ∪ B, then P(A ∪ B) = 1. If A and B are independent, so are Aᶜ and Bᶜ.

4 · Discrete random variables

E(X) = Σ x·p(x) E(X²) = Σ x²·p(x) Var(X) = E(X²) − [E(X)]² E(aX + b) = a·E(X) + b Var(aX + b) = a²·Var(X)

Binomial X ~ Bin(n, p): there are n independent trials, each with the same success probability p, and X counts successes.

P(X = x) = C(n,x) pˣ (1−p)ⁿ⁻ˣ , x = 0..n E = np Var = np(1−p)

Poisson X ~ Poisson(λ) counts events in a fixed window. If the rate is α per unit, a window of length t has λ = αt.

P(X = x) = e^(−λ) λˣ / x! , x = 0,1,2,… E = Var = λ

Geometric (§6.3): X = the trial on which the first success happens.

f(x) = p(1−p)^(x−1) , x = 1, 2, … F(x) = 1 − (1−p)^x E(X) = 1/p = return period τ Var = (1−p)/p² "Return period 25 yrs" ⇒ p = 1/25 = 0.04

Poisson approximation to the binomial (§6.5): when n ≥ 20 and np < 5, use Bin(n, p) ≈ Poisson(np).

4 · Continuous random variables

∫ f(x) dx = 1 P(a < X < b) = ∫ₐᵇ f(x) dx F(x) = P(X ≤ x) = ∫₋∞ˣ f(t) dt f(x) = F′(x) Median m: F(m) = 0.5 p-th percentile: F(xₚ) = p E(X) = ∫ x f(x) dx Var(X) = ∫ x² f(x) dx − [E(X)]²

For a continuous X, P(X = c) = 0, so ≤ and < give the same probability.

Uniform U(a, b):

f = 1/(b−a) F(x) = (x−a)/(b−a) E = (a+b)/2 Var = (b−a)²/12

Exponential Exp(λ), where λ is the rate and the mean is 1/λ:

f = λe^(−λx), x ≥ 0 F(x) = 1 − e^(−λx) P(X > x) = e^(−λx) E = 1/λ Var = 1/λ² median = ln2/λ Memoryless: P(X > s+t | X > s) = P(X > t)

In a Poisson process with rate α (§6.4), the count in a window of length t is Poisson(αt), and the waiting time until the next event is Exp(α). Keep the time units consistent: 20 minutes is 1/3 of an hour.

4.5–4.6 · Sums, max/min, transformations

CDF method for the pdf of U = g(Y):

(1) Find FY. (2) Write FU(u) = P(g(Y) ≤ u) and solve for Y. (3) Differentiate. (4) State the support of U.

Max and min of independent X₁ and X₂:

max: F(y) = F₁(y)·F₂(y)··· (parallel system) min: F(w) = 1 − [1 − F₁(w)]·[1 − F₂(w)]··· (series system) n iid: F_V(v) = [F(v)]ⁿ F_min(u) = 1 − [1 − F(u)]ⁿ min of n iid Exp(λ) ~ Exp(nλ)

Write F piecewise on every interval and check the support carefully. The pdf is the derivative of each piece.

Linear combinations:

E(aX + bY) = aE(X) + bE(Y) (always) Var(aX + bY) = a²Var(X) + b²Var(Y) (independent) Sum of n iid: E = nμ, Var = nσ²

Variances add even when you subtract the variables. A linear combination of independent normal variables is also normal.

How marks are awarded

From the practice solutions, marks go to these steps:

① Define the random variable in words. ② State its distribution with parameters, for example "Y ~ Bin(4, 0.6568)". ③ Write the formula, then substitute the numbers. ④ State the support or domain. ⑤ Give a final answer you can interpret. "Given that…, the probability that…" earns the interpretation mark.
