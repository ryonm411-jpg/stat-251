One integral does most of the work

Chapter 4.3–4.4: from a density f(x) to F(x), then to probabilities, quantiles and the mean

Most of the Chapter 4–6 questions you're struggling with run through one step. You take a density f(x) and integrate it to get the distribution function F(x). After that, interval probabilities, medians, quartiles, the max and min of several variables, and transformations all come out of F with algebra. The exponential is one density you'll do this for, and Chapter 6 gives you more. This lesson drills that one step.

The idea

The course notes' flood-level example (Example 4.2, p. 65) has density f(x) = 0.125(x − 5) for 5 < x < 9. A probability is an area under f:

Integrating from the start of the support gives F(x) = ∫₅ˣ 0.125(t − 5) dt = 0.0625(x − 5)². Every question after that is algebra, not integration:

P(6 < X < 7) = F(7) − F(6) = 0.0625(4) − 0.0625(1) = 0.1875

The recipe

  1. Find any unknown constant by setting ∫ f(x) dx = 1 over the support.
  2. Find F(x) = ∫ from the start of the support to x of f(t) dt. Write it piecewise: 0 before the support, your formula on it, and 1 after it. The piecewise form earns a mark.
  3. Interval probability: P(a < X < b) = F(b) − F(a). With a continuous X, < and ≤ give the same answer.
  4. Quantile Q(α): solve F(x) = α. The median is Q(0.5), and IQR = Q(0.75) − Q(0.25). If you get two roots, keep the one inside the support.
  5. Mean and variance: E(X) = ∫ x f(x) dx, then Var(X) = E(X²) − [E(X)]². This is the only step that needs a second integral.

For an exponential with rate λ, the recipe gives F(x) = 1 − e−λx, which is the course notes' Example 4.4. For a uniform on (a, b), it gives F(x) = (x − a)/(b − a). Learn those two results by heart. You'll use them again in lessons on max/min, Poisson processes and transformations.

Practice like the exam: work each question on paper and show every step. The first answer you enter is the one that counts. Questions 2–7 all use the same density, so each one builds on your last answer.

X is continuous with density f(x). What is P(X = 3)?
  1. f(3), the density at that point
  2. F(3), the distribution function at three
  3. 0, single points carry no probability
  4. 1−F(3), the upper tail beyond three

A single point is an interval of width 0, so ∫₃³ f(x) dx = 0. That's why f(3) is not a probability: it can be bigger than 1. It's also why P(X ≤ 3) = P(X < 3). See course notes p. 64.

X has density f(x) = c(4 − x) for 0 ≤ x ≤ 4, and 0 otherwise. Find c.

∫₀⁴ c(4 − x) dx = c[4x − x²/2]₀⁴ = c(16 − 8) = 8c = 1, so c = 1/8 = 0.125

Check: the graph is a triangle with base 4 and height 4c, so its area is ½ · 4 · 4c = 8c ✓

Same X. Which is F(x) for 0 ≤ x ≤ 4?
  1. 4x − x²/2
  2. x/2 − x²/16
  3. 1/2 − x/8
  4. x/8 − x²/32

F(x) = ∫₀ˣ (4 − t)/8 dt = (1/8)[4t − t²/2]₀ˣ = x/2 − x²/16

Check: F(0) = 0 and F(4) = 2 − 1 = 1 ✓. Option A gives F(4) = 8, which is impossible. Option C is just f(x) again. Checking F at both ends of the support catches most slips.

Full answer: F(x) = 0 for x < 0; x/2 − x²/16 for 0 ≤ x ≤ 4; 1 for x > 4.

Same X. Find P(1 < X < 3).

F(3) = 1.5 − 0.5625 = 0.9375 and F(1) = 0.5 − 0.0625 = 0.4375

P(1 < X < 3) = 0.9375 − 0.4375 = 0.5

Same X. Find the median, Med(X) = Q(0.5).

Set x/2 − x²/16 = 0.5. Multiply through by 16: 8x − x² = 8, so x² − 8x + 8 = 0.

x = (8 ± √32)/2 = 4 ± 2.828. Only 1.1716 is inside [0, 4].

The median is below 2 because the density leans toward 0: it's right-skewed.

Same X. Solving F(x) = 0.75 gives x² − 8x + 12 = 0. What is Q(0.75)?
  1. x = 6
  2. x = 4
  3. x = 3
  4. x = 2

(x − 2)(x − 6) = 0. Since 6 is outside the support [0, 4], Q(0.75) = 2.

Trap: a quadratic often gives a second root that looks fine. Always check it against the support.

Same X. Find E(X).

E(X) = ∫₀⁴ x(4 − x)/8 dx = (1/8)[2x² − x³/3]₀⁴ = (1/8)(32 − 21.333) = 4/3 ≈ 1.3333

The mean (1.33) is above the median (1.17), which fits a right skew, as in Chapter 1.

Same X. Find Var(X).

E(X²) = ∫₀⁴ x²(4 − x)/8 dx = (1/8)[4x³/3 − x⁴/4]₀⁴ = (1/8)(85.333 − 64) = 2.6667

Var(X) = 2.6667 − (1.3333)² = 2.6667 − 1.7778 = 0.8889

The waiting time X (hours) for a bus is exponential with rate λ = 0.5 per hour. Find P(X > 3).

F(x) = 1 − e−0.5x, so P(X > 3) = 1 − F(3) = e−1.5 = 0.2231

For an exponential, the upper tail is just e−λx. Put that on your cheat sheet.

Same bus. Find the median waiting time.

1 − e−0.5m = 0.5 → e−0.5m = 0.5 → −0.5m = ln 0.5 → m = ln 2 / 0.5 = 1.386 hours

Practice set 1 Q3(b) is exactly this (λ = 0.013 → 53.31 m), and it's worth 3 marks: one for F(m) = 0.5, one for taking logs, one for the answer.

The time to finish a road is uniform on (15, 20) months. Find the probability that it's done within 18 months.

F(x) = (x − 15)/5, so F(18) = 3/5 = 0.6

This is the starting point of the textbook's Problem 4.23 (solution). The project finishes when the last of three pieces finishes. That's a maximum, and it's coming in Lesson 0003.

Spaced review: two components work independently, each with probability 0.9. The system works if at least one works (parallel). Find P(system works).

P(at least one) = 1 − P(both fail) = 1 − (0.1)(0.1) = 0.99

Remember "1 − P(none)". Next lesson it becomes the formula for the minimum of random variables.

Lock it in

Tomorrow, before you open the next lesson, do this with a blank page. It takes 5 minutes. Write the five-step recipe from memory, then run it on f(x) = 3x² for 0 ≤ x ≤ 1: find F, P(0.5 < X < 1), the median, and E(X). Answers: x³, 0.875, 0.7937, 0.75. Recalling something a day later makes it stick much better than rereading it today.
