A histogram of house prices in a city has a long tail stretching to the right. Which statement is most likely true?
  1. Median is larger than the mean
  2. Mean and median are exactly equal
  3. Mean is larger than the median
  4. The IQR is larger than the range

A right tail (right skew) pulls the mean toward the big values. The median doesn't move much. So mean > median. Practice set 1 Q1(iii) asks exactly this. The IQR can never be larger than the range.

A factory has three machines. A makes 50% of the items, B makes 30% and C makes 20%. Their defect rates are 2%, 3% and 5%. Find the probability that a randomly chosen item is defective.

Let D = the item is defective. By the law of total probability:

P(D) = P(D|A)P(A) + P(D|B)P(B) + P(D|C)P(C) = 0.02(0.5) + 0.03(0.3) + 0.05(0.2) = 0.029

This is the same setup as practice set 2 Q3(a), the risk-level question. Define the events first. That earns a mark.

X ~ N(50, 16). Find P(X > 56).

Trap: in this course N(μ, σ²) puts the variance second. So σ = √16 = 4, not 16. Practice set 1 Q4 gives a mark just for spotting this.

P(X > 56) = P(Z > (56 − 50)/4) = P(Z > 1.5) = 1 − 0.9332 = 0.0668

X has density f(x) = kx² for 0 ≤ x ≤ 3, and 0 otherwise. Find k.

∫₀³ kx² dx = k[x³/3]₀³ = 9k = 1, so k = 1/9 ≈ 0.1111

Calls reach a help desk as a Poisson process with rate 3 per hour. Find the probability of exactly 2 calls in a 30-minute period.

First, rescale the rate to the time window: 30 min = 0.5 h, so X ~ Poisson(3 × 0.5 = 1.5).

P(X = 2) = e−1.5 1.5² / 2! = 0.2231 × 1.125 = 0.2510

Practice set 3 Q3(c) also rescales: 8 per hour × 2.5 h → Poisson(20).

X and Y are independent with Var(X) = 4 and Var(Y) = 1. Find Var(2X − 3Y).

Var(aX + bY) = a²Var(X) + b²Var(Y) when X and Y are independent. Constants come out squared, so the minus sign disappears:

Var(2X − 3Y) = 4(4) + 9(1) = 25

Trap: variances never subtract. The answers 4(4) − 9(1) = 7 and 2(4) − 3(1) = 5 are both wrong.

Same factory as Q2. An item is found to be defective. What is the probability that it came from machine C?

Bayes: P(C|D) = P(D|C)P(C) / P(D) = 0.05(0.2) / 0.029 = 0.010 / 0.029 = 0.3448

Machine C makes only 20% of the items, yet it accounts for 34% of the defects. Bayes questions are often built to show a jump like that.

Same X as Q4, with f(x) = x²/9 on [0, 3]. Find P(X > 2).

F(x) = ∫₀ˣ t²/9 dt = x³/27 for 0 ≤ x ≤ 3. Check: F(3) = 1 ✓

P(X > 2) = 1 − F(2) = 1 − 8/27 = 19/27 ≈ 0.7037

In any year, a river floods with probability 0.04, independently of other years. Find the probability that the first flood happens in year 3.

Let X be the year of the first flood, so X ~ Geometric(p = 0.04) and P(X = k) = (1 − p)k−1p:

P(X = 3) = 0.96² × 0.04 = 0.0369

The return period is E(X) = 1/p = 25 years. That means "a 25-year flood". It does not mean a flood happens exactly every 25 years.

Same X ~ N(50, 16). Find P(46 < X < 58).

z-values: (46 − 50)/4 = −1 and (58 − 50)/4 = 2.

P(−1 < Z < 2) = P(Z < 2) − P(Z < −1) = 0.9772 − (1 − 0.8413) = 0.8185

For a negative z, use symmetry: P(Z < −1) = 1 − P(Z < 1). Practice set 3 Q2(a) is the same pattern.

A system has 3 independent components in series, so it fails as soon as any one component fails. Each lifetime is exponential with rate λ = 0.1 per year. Find the probability that the system lasts more than 5 years.

A series system fails when the first component fails, so its lifetime is Y = min(X₁, X₂, X₃).

P(Y > 5) = P(all three > 5) = [P(X > 5)]³ = (e−0.5)³ = e−1.5 = 0.2231

Rule: for a min, work with P(Y > y). For a max, work with P(Y ≤ y). Either way, independence turns "all of them" into a product.

Exam scores have a standard deviation of 4. Every score is doubled, and then 5 points are added. What is the new standard deviation?
  1. 13
  2. 8
  3. 4
  4. 21

Adding a constant shifts every score but doesn't change the spread. Multiplying by 2 doubles the spread. New SD = 2 × 4 = 8. The variance would become 4 × 16 = 64.

Practice set 1 Q1(v)–(vi): adding 5 changes the median and the quartiles, but not the IQR or the SD.

Y has density f(y) = 2y for 0 ≤ y ≤ 1. Let U = 4Y − 1. Which is the density of U?
  1. (u + 1)/4 on −1 ≤ u ≤ 3
  2. (u + 1)/8 on 0 ≤ u ≤ 1
  3. 2u on −1 ≤ u ≤ 3
  4. (u + 1)/8 on −1 ≤ u ≤ 3

Go through F, never straight to f. FY(y) = y².

G(u) = P(4Y − 1 ≤ u) = P(Y ≤ (u+1)/4) = ((u+1)/4)²

g(u) = G′(u) = 2(u+1)/16 = (u + 1)/8

Support: y = 0 → u = −1 and y = 1 → u = 3. Check that the area is 1: ∫₋₁³ (u+1)/8 du = 16/16 = 1 ✓. Practice set 2 Q2 uses the same method with U = 3Y − 1.

Same help desk (3 calls per hour). A call just arrived. Find the probability that the wait for the next call is more than 40 minutes.

The time T between events in a Poisson process is exponential with the same rate: T ~ Exp(3) in hours. 40 min = 2/3 h.

P(T > 2/3) = e−3(2/3) = e−2 = 0.1353

Trap: convert the time to match the rate's units first. e−3×40 is wrong. Practice set 3 Q3(b) is this question.

P(A) = 0.4, P(B) = 0.5 and P(A ∪ B) = 0.7. Which is correct?
  1. Not independent; P(A ∩ B) = 0.20
  2. Independent; P(A ∩ B) = 0.20
  3. Independent; P(A ∩ B) = 0.10
  4. Not independent; P(A ∩ B) = 0.30

Rearrange the addition rule: P(A ∩ B) = 0.4 + 0.5 − 0.7 = 0.2.

Then check P(A)P(B) = 0.4 × 0.5 = 0.2, which equals P(A ∩ B), so they are independent. Write out both numbers and the comparison. Practice set 1 Q2(a)(ii) gives 2 marks for that line.

Don't mix up independent with disjoint. Disjoint means P(A ∩ B) = 0, and two disjoint events with non-zero probabilities can never be independent.

Same X ~ N(50, 16). Find the value c such that only 10% of X values are above c. Use the z-table and round z to 2 decimals.

Only 10% above means 90% below, so c is the 90th percentile. Search the inside of the table for 0.90. The closest entry is 0.8997, at z = 1.28.

(c − 50)/4 = 1.28 → c = 50 + 4(1.28) = 55.12

This is reading the table backwards (probability → z). Practice set 3 Q2(b) is worth 3 marks: one for the set-up, one for the table value and one for the answer.

Same X as Q4 (F(x) = x³/27 on [0, 3]). Find the median.

x³/27 = 0.5 → x³ = 13.5 → x = 13.51/3 = 2.381

The median is above 1.5, the midpoint of [0, 3], because this density puts more weight on large values.

From Q3, P(X > 56) = 0.0668 for one item. Four items are chosen independently. Find the probability that at least one of them has X > 56.

Let W be the number of items (out of 4) with X > 56, so W ~ Bin(4, 0.0668).

P(W ≥ 1) = 1 − P(W = 0) = 1 − (1 − 0.0668)⁴ = 1 − 0.9332⁴ = 0.2416

Practice set 3 Q2(c) and Q4(a) both chain a normal probability into a binomial. Expect this on the exam. Saying "Y ~ Bin(n, p)" earns its own half mark.

X₁ and X₂ are independent, each Uniform(0, 10). Let Y = max(X₁, X₂). Find the median of Y.

FY(y) = P(X₁ ≤ y, X₂ ≤ y) = (y/10)(y/10) = y²/100 for 0 ≤ y ≤ 10.

y²/100 = 0.5 → y = √50 = 7.071

Practice set 1 Q5 is the harder version, with two different uniforms. That gives a piecewise F and needs care with the support. Look at it again after this.

X has this pmf: P(0) = 0.10, P(1) = 0.25, P(2) = 0.30, P(3) = 0.20, P(4) = 0.15. Find P(X ≤ 3 | X ≥ 1).

P(X ≤ 3 | X ≥ 1) = P(1 ≤ X ≤ 3) / P(X ≥ 1) = (0.25 + 0.30 + 0.20) / 0.90 = 0.75/0.90 = 0.8333

The numerator is the overlap of the two conditions. Practice set 2 Q1(d) has the same shape.

Same Y as Q13 (f(y) = 2y on [0, 1]) and U = 4Y − 1. Find E(U).

Shortcut: expectation is linear, so E(U) = 4E(Y) − 1. E(Y) = ∫₀¹ y · 2y dy = 2/3.

E(U) = 4(2/3) − 1 = 5/3 ≈ 1.667

You could also compute ∫ u g(u) du, as practice set 2 Q2(b) does. Linearity is quicker and safer.

A chip is defective with probability 0.004. In a batch of 500 chips, use the Poisson approximation to find P(at most 1 defective).

X ~ Bin(500, 0.004). n is large and p is small, so X ≈ Poisson(λ = np = 2).

P(X ≤ 1) ≈ e−2(1 + 2) = 3e−2 = 0.4060

State the approximation and why it's allowed (n large, p small). That's part of the marks.

Same X ~ N(50, 16). Find P(|X − 50| < 6).

Remove the absolute value: |X − 50| < 6 ⇔ 44 < X < 56 ⇔ −1.5 < Z < 1.5.

P = 2(0.9332) − 1 = 0.8664

For ">", take the complement. Practice set 1 Q4 is P(|X − 5| > 2), and the interval there is not centred on the mean, so you need two separate z-values.

Same river as Q9 (p = 0.04 per year). Find the probability of at least one flood in the next 10 years.

P(at least one) = 1 − P(none in 10 years) = 1 − 0.96¹⁰ = 0.3352

The same answer from a geometric view is P(first flood ≤ 10) = 1 − (1 − p)¹⁰. So the chance of a "25-year flood" in any 10-year stretch is about 1 in 3.

A rod's length has mean 50 cm and SD 3 cm. Four independent rods are laid end to end. What is the SD of the total length?
  1. 12 cm
  2. 36 cm
  3. 6 cm
  4. 1.5 cm

Add the variances, not the SDs. Var(total) = 4 × 3² = 36, so SD = √36 = 6 cm. The mean of the total is 200 cm.

For the average of 4 rods, the SD is 3/√4 = 1.5. Practice set 2 Q1(e) tests this.

Bonus (normal approximation to the binomial, from practice set 3; it may not be on the exam). X ~ Bin(100, 0.3). Use the normal approximation with continuity correction to find P(X ≤ 25). Round z to 2 decimals.

np = 30 ≥ 5 and n(1 − p) = 70 ≥ 5 ✓. μ = 30, σ² = np(1 − p) = 21.

P(X ≤ 25) ≈ P(Z ≤ (25.5 − 30)/√21) = P(Z ≤ −0.98) = 1 − 0.8365 = 0.1635

"≤ 25" becomes 25.5 with the continuity correction. Practice set 3 Q4(b) does the same thing.
