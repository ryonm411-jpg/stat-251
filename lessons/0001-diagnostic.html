A 30-minute diagnostic covering everything on the October 30 midterm

How to take it, so the results mean something:

Use paper, a pen and your calculator. Don't look at notes or the formula sheet. That's harder than the exam, where you'll have your cheat sheet, and it's meant to be: recalling a formula from memory is what makes it stick (Roediger & Karpicke, 2006).

Your first answer is the one that counts. If you have no idea, guess, then read the worked solution. A wrong answer here costs you nothing and still tells us something useful.

Round probabilities to 4 decimals. Fractions like 4/7 and percentages work too.

Show the z-table (the exam provides one like it)
The scores on an exam have mean 64 and median 71. Which shape best describes the distribution?
  1. Left-skewed: long tail toward low scores
  2. Right-skewed: long tail toward high scores
  3. Symmetric: matching tails toward both ends
  4. Uniform: flat with no tail visible

The mean gets pulled toward the long tail and the median doesn't. Mean < median means the tail points down, so the distribution is left-skewed.

Trap: "skewed left" names the side the tail is on, not the side the peak is on. On the exam this is practice set 1 Q1(iii), turned around.

A data set has SD = 10 and IQR = 14. Every value is transformed by new = 1.2 × old + 5. What are the new SD and IQR?
  1. SD = 17, IQR = 21.8
  2. SD = 12, IQR = 16.8
  3. SD = 15, IQR = 19.0
  4. SD = 12, IQR = 21.8

Adding a constant shifts every value, so it changes centres (mean, median, quartiles) but leaves spread alone. Multiplying by b multiplies every spread measure by |b|.

SD = 1.2 × 10 = 12 and IQR = 1.2 × 14 = 16.8. The "+5" has no effect on either.

Trap: the variance would change by 1.2² = 1.44, but the SD only changes by 1.2.

P(A) = 0.5, P(B) = 0.4 and P(A ∪ B) = 0.7. A and B are:
  1. Mutually exclusive, but not independent
  2. Independent, but not mutually exclusive
  3. Both independent and mutually exclusive
  4. Neither independent nor mutually exclusive

Start with the addition rule: P(A ∩ B) = 0.5 + 0.4 − 0.7 = 0.2.

Since 0.2 ≠ 0, A and B are not mutually exclusive. Since P(A)P(B) = 0.5 × 0.4 = 0.2 = P(A ∩ B), they are independent.

Trap: two disjoint events that each have positive probability can never be independent. If one happens, the other can't.

A factory buys a part from three suppliers. 50% of parts come from S1, 30% from S2 and 20% from S3. Their defect rates are 2%, 4% and 10%. What is the probability that a randomly chosen part is defective?

Use the law of total probability: P(D) = Σ P(D | Si) P(Si)

= 0.02(0.5) + 0.04(0.3) + 0.10(0.2) = 0.010 + 0.012 + 0.020 = 0.042

This is the same structure as practice set 2, Q3(a).

Same factory. A part turns out to be defective. What is the probability that it came from S3?

Use Bayes' rule: P(S3 | D) = P(D | S3) P(S3) / P(D) = 0.020 / 0.042 = 0.4762

S3 supplies only 20% of parts but produces almost half of the defects. That kind of reversal is why Bayes questions get asked.

Trap: the numerator is one term from the total-probability sum, not P(D | S3) by itself.

Find P(X ≥ 2 | X ≥ 1).

P(X ≥ 2 | X ≥ 1) = P(X ≥ 2 and X ≥ 1) / P(X ≥ 1) = P(X ≥ 2) / P(X ≥ 1)

= (0.4 + 0.2) / (0.3 + 0.4 + 0.2) = 0.6 / 0.9 = 0.6667

Practice set 2, Q1(d) has the same shape.

Same X as the previous question. Find Var(X).

E(X) = 0(0.1) + 1(0.3) + 2(0.4) + 3(0.2) = 1.7

E(X²) = 0(0.1) + 1(0.3) + 4(0.4) + 9(0.2) = 3.7

Var(X) = E(X²) − [E(X)]² = 3.7 − 2.89 = 0.81

Trap: [E(X)]² is not E(X²). You square the mean after you compute it.

A quiz has 8 multiple-choice questions with 4 options each. A student guesses every answer at random. What is the probability they get exactly 3 right?

X ~ Bin(n = 8, p = 0.25). The trials are independent and each has the same chance of success.

P(X = 3) = C(8,3)(0.25)³(0.75)⁵ = 56 × 0.015625 × 0.23730 = 0.2076

Emails arrive as a Poisson process at 3 per hour. What is the probability that at most 1 email arrives in a 30-minute window?

First scale the rate to the window: λ = 3 per hour × 0.5 hour = 1.5. So X ~ Poisson(1.5).

P(X ≤ 1) = e−1.5(1.5⁰/0! + 1.5¹/1!) = 0.22313 × 2.5 = 0.5578

Trap: if you used λ = 3, you forgot to rescale. Practice set 3 Q3(c) tests the same step (8/hr × 2.5 hr = 20).

X has pdf f(x) = x/8 for 0 ≤ x ≤ 4, and 0 otherwise. Find the median of X.

First find the CDF: F(x) = ∫₀ˣ t/8 dt = x²/16 for 0 ≤ x ≤ 4.

Then set F(m) = 0.5: m²/16 = 0.5, so m² = 8 and m = √8 = 2.828

This is the same method as the exponential median in practice set 1, Q3(b): find F, then solve F(m) = 0.5.

A battery's lifetime is exponential with a mean of 5 years. Given that the battery has already lasted 4 years, what is the probability that it lasts more than 7 years in total?

The mean is 1/λ, so λ = 1/5 = 0.2.

P(X > 7 | X > 4) = P(X > 7) / P(X > 4) = e−1.4 / e−0.8 = e−0.6 = 0.5488

This is the memoryless property: the answer equals P(X > 3), as if the battery were new.

Trap: if you used λ = 5, you mixed up the mean and the rate. Read whether the question gives you the mean or λ.

X ~ N(50, 16). Find P(X > 56). (Use the z-table.)

In this course, N(μ, σ²) gives the variance as the second number. So σ = √16 = 4. Practice set 1, Q4 points this out in the margin.

P(X > 56) = P(Z > (56 − 50)/4) = P(Z > 1.5) = 1 − 0.9332 = 0.0668

Trap: if you used σ = 16, you got z = 0.375 and an answer near 0.35.

Heights are N(170, 8²) cm. Only 10% of people are taller than what height?

"10% are taller" means you want the 90th percentile. In the body of the table, find the entry closest to 0.9000. It's 0.8997, at z = 1.28.

x = μ + zσ = 170 + 1.28(8) = 180.24 cm

Here you use the table backwards: you start from a probability and look up z. Practice set 3, Q2(b) does the same.

X ~ Bin(100, 0.3). Using the normal approximation with continuity correction, find P(X ≤ 25).

Check the conditions: np = 30 ≥ 5 and n(1−p) = 70 ≥ 5. Then μ = np = 30 and σ = √(np(1−p)) = √21 = 4.583.

For "≤ 25", the continuity correction uses 25.5: P(X ≤ 25) ≈ P(Z ≤ (25.5 − 30)/4.583) = P(Z ≤ −0.98)

= 1 − 0.8365 = 0.1635

Trap: without the correction you get z = −1.09 and 0.1379. The rule: "≤ k" becomes k + 0.5, and "< k" becomes k − 0.5. Practice set 3, Q4(b) uses it too.

X and Y are independent. E(X) = 20, SD(X) = 3, E(Y) = 15 and SD(Y) = 4. Find Var(2X − Y).

Var(aX + bY) = a²Var(X) + b²Var(Y) when X and Y are independent.

Var(2X − Y) = 4(9) + (−1)²(16) = 36 + 16 = 52

Trap 1: variances add even when you subtract the variables. Trap 2: square the SDs before you combine them. Practice set 2, Q1(e): 5 × 2² = 20.

X has pdf f(x) = 2x on 0 ≤ x ≤ 1. Let W = 4X + 2. What is the pdf of W?
  1. (w − 2)/4 for 2 ≤ w ≤ 6
  2. (w − 2)/16 for 2 ≤ w ≤ 6
  3. (w − 2)/8 for 2 ≤ w ≤ 6
  4. (w + 2)/8 for 2 ≤ w ≤ 6

Use the CDF method, as in practice set 2 Q2(a). FX(x) = x², so

FW(w) = P(4X + 2 ≤ w) = P(X ≤ (w−2)/4) = ((w−2)/4)² = (w−2)²/16

Differentiate: fW(w) = 2(w−2)/16 = (w−2)/8 on 2 ≤ w ≤ 6

Quick check: ∫₂⁶ (w−2)/8 dw = 16/16 = 1 ✓. Option A integrates to 2 and option B to ½, so neither is a valid pdf. Doing this check catches most algebra slips.

X₁ and X₂ are independent, each U(0, 10). Let M = min(X₁, X₂). Find P(M ≤ 4).

The min is above 4 only if both values are above 4. So

P(M ≤ 4) = 1 − P(X₁ > 4)P(X₂ > 4) = 1 − (0.6)(0.6) = 0.64

For the max, flip it: P(max ≤ y) = P(X₁ ≤ y)P(X₂ ≤ y). Practice set 1 Q5 (max) and practice set 2 Q5 (min) both rely on this.
