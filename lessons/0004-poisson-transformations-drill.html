Part A · Poisson process: two questions, two formulas

Every Poisson-process question asks about one of two things. Decide which one first:

The question asks about…Random variableFormula
How many events in a window of length tX ~ Poisson(μ), with μ = λtP(X = k) = e−μ μk / k!
How long until the next eventT ~ Exp(λ)P(T > t) = e−λt

The patterns that come up most:

P(none) = e−μ · P(at least 1) = 1 − e−μ · P(at most 1) = e−μ(1 + μ) · P(at least 2) = 1 − e−μ(1 + μ)

E(X) = Var(X) = μ, so SD = √μ. For the Poisson approximation to Bin(n, p), with n large and p small, use μ = np. Units: convert the time into the rate's units before multiplying. (Course notes §6.4, p. 108)

For every question below, write "X = …, X ~ …" before you calculate anything. That line is worth marks on its own.

Emails arrive as a Poisson process at 4 per hour. Find P(no emails in the next 15 minutes).

Let X = the number of emails in 15 min = 0.25 h, so X ~ Poisson(μ = 4 × 0.25 = 1).

P(X = 0) = e−1 = 0.3679

Same emails. Find P(exactly 3 emails in one hour).

X ~ Poisson(4). P(X = 3) = e−4 4³ / 3! = 0.01832 × 64 / 6 = 0.1954

Same emails. Find P(at least 2 emails in 30 minutes).

X ~ Poisson(4 × 0.5 = 2). "At least 2" = 1 − P(0) − P(1):

1 − e−2(1 + 2) = 1 − 0.4060 = 0.5940

This is practice set 3 Q3(a) with different numbers. There, "method" earned 2 marks and the answer earned 1.

An email just arrived. Find the probability that you wait more than 45 minutes for the next one.

This asks how long, so T ~ Exp(4) in hours. 45 min = 0.75 h.

P(T > 0.75) = e−4(0.75) = e−3 = 0.0498

You can also think of it this way: waiting more than 45 minutes means zero emails in 45 minutes, which is P(Poisson(3) = 0) = e−3. Both views give the same answer, so use whichever you remember.

Find the median waiting time between emails, in minutes.

Set F(m) = 0.5: 1 − e−4m = 0.5 → e−4m = 0.5 → m = ln 2 / 4 = 0.1733 h = 10.40 min

This is the same three-mark pattern as practice set 1 Q3(b), the kangaroo rats.

Find the standard deviation of the number of emails in a 2-hour period.

W ~ Poisson(8), and E(W) = Var(W) = 8, so SD = √8 = 2.828. This is practice set 3 Q3(c).

A light bulb is faulty with probability 0.002. Use the Poisson approximation to find P(exactly 2 faulty bulbs) in a box of 1000.

X ~ Bin(1000, 0.002) ≈ Poisson(np = 2), since n is large and p is small.

P(X = 2) ≈ e−2 2² / 2! = 2e−2 = 0.2707

Part B · Transformations: go through F, then use the chain rule

  1. Find FY(y) from f(y).
  2. Write G(u) = P(U ≤ u) and rearrange the inside until you have Y ≤ (something in u).
  3. Substitute that "something" into FY.
  4. Differentiate to get g(u) = G′(u). Use the chain rule: differentiating ((u+1)/4)² gives 2 · (u+1)/4 · 1/4. That 1/4 is the factor you dropped on the mock.
  5. Find the new support by putting the endpoints of y into U. As a free check, the new density's area must be 1.

Shortcut for E and Var: if U = aY + b, then E(U) = aE(Y) + b and Var(U) = a²Var(Y). You don't need g(u) for these.

Y has f(y) = 3y² for 0 ≤ y ≤ 1. Let U = 2Y + 1. Find P(U ≤ 2).

FY(y) = y³. P(2Y + 1 ≤ 2) = P(Y ≤ 0.5) = 0.5³ = 0.125

That's steps 1–3. Often you never need the density of U at all.

Same Y and U = 2Y + 1. Which is the density of U?
  1. 3(u−1)²/2 on 1 ≤ u ≤ 3
  2. 3(u−1)²/8 on 1 ≤ u ≤ 3
  3. 3(u−1)²/8 on 0 ≤ u ≤ 1
  4. ((u−1)/2)³ on 1 ≤ u ≤ 3

G(u) = P(Y ≤ (u−1)/2) = ((u−1)/2)³

g(u) = 3((u−1)/2)² · ½ = 3(u−1)²/8, on 1 ≤ u ≤ 3

A forgets the chain-rule ½: its area is 4, not 1. C has the wrong support, since y ∈ [0, 1] maps to u ∈ [1, 3]. D is G, not g.

Same Y and U = 2Y + 1. Find E(U).

E(Y) = ∫₀¹ y · 3y² dy = 3/4. E(U) = 2(3/4) + 1 = 2.5

E(Y) = ∫ y f(y) dy. Multiply by y first, then integrate. Integrating f(y) on its own just gives 1.

Same Y and U = 2Y + 1. Find Var(U).

E(Y²) = ∫₀¹ y² · 3y² dy = 3/5. Var(Y) = 0.6 − 0.75² = 0.0375.

Var(U) = 2² × 0.0375 = 0.15. The +1 has no effect on the variance.

Part C · One more try at everything else you missed

These are the same ideas as your other misses, with new numbers. If you get one right this time, that topic is fixed.

60% of a company's email goes through server X and 40% through server Y. Spam rates are 10% on X and 25% on Y. Find P(an email is spam).

Let S = the email is spam. P(S) = 0.1(0.6) + 0.25(0.4) = 0.06 + 0.10 = 0.16

Write each product on its own line before adding. That catches arithmetic slips like 0.026 vs 0.029 on the mock.

Same company. An email is spam. Find the probability that it went through server Y.

P(Y|S) = P(S|Y)P(Y) / P(S) = 0.10 / 0.16 = 0.625

On the mock you stopped at the numerator (0.01). Bayes always divides by the total from the step before. The answer to a Bayes question is never smaller than its numerator.

X ~ N(100, 25). Find P(X < 93).

σ = √25 = 5. z = (93 − 100)/5 = −1.4.

P(Z < −1.4) = 1 − P(Z < 1.4) = 1 − 0.9192 = 0.0808

Same X ~ N(100, 25). Find P(92 < X < 105).

z-values: −1.6 and 1. P(Z < 1) − P(Z < −1.6) = 0.8413 − (1 − 0.9452) = 0.7865

Sketch the bell curve and shade the region every time. It takes 5 seconds and catches sign errors.

From the previous question but one, P(X < 93) = 0.0808 for one item. Five items are tested independently. Find P(at least one has X < 93).

Let W be the number (out of 5) with X < 93, so W ~ Bin(5, 0.0808).

P(W ≥ 1) = 1 − (0.9192)⁵ = 0.3438

A bag of sand has mean weight 20 kg and SD 0.5 kg. Find the SD of the total weight of 9 independent bags.
  1. 4.5 kg
  2. 2.25 kg
  3. 1.5 kg
  4. 0.17 kg

Var(total) = 9 × 0.5² = 2.25, so SD = √2.25 = 1.5 kg. 4.5 comes from adding SDs (the mock trap), 2.25 is the variance, and 0.17 is the SD of the average (0.5/√9).

Two independent parts have exponential lifetimes with rate 0.2 per year. In series (the system dies when either part dies), find P(system lasts more than 2 years).

Series → min. P(min > 2) = P(both > 2) = (e−0.4)² = e−0.8 = 0.4493

The same two parts in parallel (the system dies only when both are dead). Find P(the system dies within 2 years).

Parallel → max. P(max ≤ 2) = P(both ≤ 2) = (1 − e−0.4)² = 0.3297² = 0.1087

Memory hook: series = min = P(>), parallel = max = P(≤).
